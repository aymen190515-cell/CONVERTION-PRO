# CONVERTION-PRO Assets

Vehicle-specific visual assets are stored independently from the application UI.

## Structure

clusters/<vehicle_profile>/
- front.png
- rear.png
- connector.png

cables/
- <cable_id>.png

branding/
- application branding assets
